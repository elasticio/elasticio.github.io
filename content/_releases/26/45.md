## New Features
### Two-factor authentication (2FA) is now mandatory on app.elastic.io
Two-factor authentication (2FA) is now required for all users on app.elastic.io. Previously, it was optional and enabled at the user's discretion. To improve platform security, it can no longer be skipped.

We ask all users to set up two-factor authentication. You can do it in your user profile - see [User Profile Information](/getting-started/user-profile-information#two-factor-authentication) for step-by-step instructions.

### Automatic workspace creation for newly registered users
A default workspace is now created automatically when a new user registers. The workspace uses the workspace type configured for the tenant and is named after the user's email prefix. Its resource usage is included in quota calculations.

### Autosaving for the Notes section in Flow Designer
The Notes section in Flow Designer now saves automatically, so your changes are kept without a manual save.

### Node.js update on the platform
The platform's Node.js runtime has been updated to `v24.22.1` LTS, incorporating the latest security fixes and dependency updates. This update addresses multiple vulnerabilities, including issues affecting Brotli decoding, DNS resolution and TLS certificate validation.

## Fixed Bugs
*   **IMPROVED** the Flow Designer on React and the copy/paste functionality for flow steps.
*   **FIXED** user quota calculation for support access. Support users are now correctly excluded from the contract user quota usage (`per_contract_user_count_limit`), so granting support access no longer increases the consumed user quota or prevents adding regular contract members when the user limit is reached.
*   **FIXED** the Maester error `Server error during request: "timeout of 20000ms exceeded"`.
