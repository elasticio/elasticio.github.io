## New Features
### Component Usage Insights
Introduced a new `GET /v2/tenants/:tenantId/connector-usage` endpoint that returns connector usage statistics across tenant workspaces. Access is restricted to tenant administrators only.

For detailed information, please refer to the API documentation:
* [Tenants Connector Usage](https://api.{{site.data.tenant.name}}docs/v2#/tenants/get_tenants__tenant_id__connector_usage)

### Notes Field in Flow Designer
We have introduced a new **Notes** section under the Flow Designer's dropdown menu.
* Please note that runtime text auto-saving and Markdown support are not implemented.
* You can use the built-in text formatter and click the floppy disk icon to save your notes.

{% include img.html max-width="100%" url="/assets/img/RN/2627/notes-field.png" title="Flow Designer Notes Section" %}

### Resizable Columns on Logs Page
The column widths on the **Logs** page are now resizable. Simply hover your mouse over the border of a column in the Logs table and drag to adjust its width.

{% include img.html max-width="100%" url="/assets/img/RN/2627/resizable-columns.png" title="Resizable Columns on Logs Page" %}

## Fixed Bugs
*   **FIXED** an issue where the vertical line connecting steps in the Flow Designer was missing.
